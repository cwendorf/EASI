# [`EASI`](https://github.com/cwendorf/EASI)

## Combine

### Description

Combine multiple frames of summary statistics into a list.

### Usage

```r
combine.default(..., class="NULL")
```

### Arguments

- **`...`**: a set of vectors to combine into a list
- **`class`**: specified class of the list

### Value

The returned list should include multiple frames of the same type (bsm, wsm or cor).
