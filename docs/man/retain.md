# [`EASI`](https://github.com/cwendorf/EASI)

## Retain

### Description

Retain a frame following other calculations.

### Usage

```r
retain.default(x, name)
```

### Arguments

- **`x`**: the frame to be retained
- **`name`**: the name for the frame

### Value

The function retains (assigns) the previously calculated frame from previous calculations.
